## 소스별 상세

### 1. 나라장터 (조달청) — ✅ 가능

- **근거**: 공공데이터법 제3조(기본원칙)는 공공기관이 공공데이터의 **영리적 이용을 금지·제한할 수 없다**고 명시. 조달청은 개방 조달데이터의 상업 활용을 적극 홍보(연 500억 부가가치 창출 사례).
- **대상 API**: 입찰공고정보서비스(data.go.kr ID 15129394), 낙찰정보서비스(15129397), 계약정보서비스(15129427), 공공데이터개방표준서비스(15058815).
- **실무**: 회원가입 → 활용신청(대부분 자동승인) → serviceKey 발급. 개발계정 통상 일 10,000회, 운영계정 전환 시 증량. 인증키 양도·공유 금지.

### 2. 지방재정365 / 열린재정 — ✅ 가능 (경로 선택 주의)

- **지방재정365**: 자체 Open API + 공공데이터포털 등록본(예산서 15138708, 재정공시 15138709 등) 병존. **data.go.kr 경로 이용 시 공공데이터법 적용으로 법적 근거가 가장 명확** → 이 경로 권장.
- **열린재정**: OPEN API 제공(약 150개 데이터셋). 공공누리 제3유형(출처표시+변경금지 — 상업 이용 가능) 적용으로 안내되나 2차 자료 기반 → **사이트 저작권 정책 원문 확인 필요** (제4유형이면 상업 이용 금지이므로 반드시 구분).

### 3. DART 전자공시 — 🟡 조건부 가능

- **가능 근거**: "개인·**기업**·기관 누구든지 이용 가능" 명시, 금감원이 민간 서비스 개발 공식 장려. 다수 핀테크가 상업 서비스에 활용 중.
- **주의**: 이용약관에 "API 이용 결과물에 이용료 부과 불가" 취지 조항 존재 가능(= API 데이터의 유료 재판매 금지). **Epson 사내 활용은 재판매가 아니므로 저촉 소지 낮음** — 도입 전 opendart.fss.or.kr/intro/terms.do 원문 확인.
- **실무**: 무료 인증키 즉시 발급(기업 명의 가능). 쿼터 일 10,000~20,000건 수준(현행 수치는 FAQ 확인). 대량 수집은 공시원문 XML 일괄 다운로드 API 병용.

### 4. 네이버 데이터랩 — 🟡 조건부 가능 (저장·재가공이 핵심 리스크)

- **가능 근거**: 무료 제공, 기업 명의 애플리케이션 등록 절차 존재. FAQ의 '상업적 이용 불가' 정의는 좁음(직접 수익화·광고 병기·유료회원 전용 화면).
- **핵심 리스크**: 약관 7.3③ + FAQ — "단순 캐시 목적이 아니라면 **별도 저장·재가공 불허**". MI 플랫폼처럼 **검색량 시계열을 장기 축적·재가공하는 방식이 정확히 이 조항과 충돌**.
- **데이터 한계**: 절대 검색량이 아닌 **상대지수**(구간 내 최대값=100). 호출 기간 설정에 따라 값이 달라져 여러 호출을 이어 붙이면 왜곡됨.
- **쿼터**: 검색어트렌드 일 1,000회. 다중 키로 쿼터 우회 금지(7.3⑤).
- **권장 경로**: ① 사내 이용 범위에 대한 네이버 공식 질의 ② 제휴 신청(navercorp.com/naver/proposalGuide) ③ **네이버클라우드(NCP) Search Trend 유료 API** — 기업용 계약 체계라 상업 이용이 계약상 가장 깔끔.

### 5. 채용공고 크롤링 — ❌ 불가/고위험

- **판례**: 잡코리아 v 사람인 — 대법원 2017.8.24. 확정. 채용정보 반복·체계적 크롤링을 **저작권법상 데이터베이스제작자 권리 침해**로 판단, 전량 폐기+배상 명령, 이후 합의금 120억. 크롤링 대상 당사자들이 직접 만든 판례로, 탐지·법적 대응에 극히 적극적.
- **참고**: 대법원 2021도1533(야놀자 v 여기어때)은 형사(정보통신망 침입)는 부정했으나 **민사 리스크(DB권·부정경쟁방지법)는 그대로**. "사내용"이라도 DB의 상당 부분 반복 복제 자체가 침해.
- **대안**:
  1. **워크넷/고용24 채용정보 Open API** (한국고용정보원, data.go.kr) — 공공데이터라 상업 활용 제약 거의 없음. **기본 데이터원으로 권장.**
  2. 사람인 공식 Open API(oapi.saramin.co.kr) — 일 500회, 재판매·유료화 금지. "사내 영업 인텔리전스" 용도 허용 여부를 api@saramin.co.kr 에 사전 확인.
  3. 잡코리아는 공개 API 없음 → B2B 데이터 공급 제휴 문의가 유일 경로.

### 6. 교육청 입찰공고 웹 게시 — 🟢 조건부 가능 (저위험, 대부분 불필요)

- **근거**: 입찰공고는 공공저작물 자유이용(저작권법 §24조의2) 대상이고, 사실 전달 고지문이라 저작물성 자체가 약함. 권리 주장 주체가 공공기관이며 공공데이터법은 개방을 의무화하는 방향.
- **실무**: 교육청 입찰 대부분이 나라장터 경유 → **나라장터 API로 커버, 크롤링은 미등재 소규모 공고 보충용으로만.** 수집 시 robots.txt 존중, 요청 간격 수 초 이상(야간 배치), 식별 가능 User-Agent, 출처 표시, 개인정보 포함 첨부 배제.
- **정식 경로**: API에 없는 데이터는 공공데이터포털 '공공데이터 제공신청' 제도로 해당 교육청에 개방 요청 가능(법정 기한 내 회신 의무).

### 7. 기술 트렌드 시그널 소스 4종 (2026-07-30 추가)

- **KIPRIS(특허) — ✅ 가능**: 특허청 KIPRIS Plus가 기업·상업 서비스용 API를 공식 제공. 무료 쿼터 초과 시 유료 전환이므로 수집 주기(일 배치)로 쿼터 관리.
- **NTIS(국가R&D 과제) — ✅ 가능**: 공공데이터법 적용. 과제 공고·성과 정보 OpenAPI 활용신청으로 즉시 사용 가능.
- **빅카인즈(뉴스) — 🟡 조건부**: 서비스는 언론진흥재단이 운영하지만 **기사 저작권은 각 언론사에 있음**. 상업적 목적의 본문 저장·재가공은 유료 약정 대상 — 예시 데이터는 이를 반영해 요약+원문 링크만 보관하는 구조로 설계함. 무약정 단계에서는 메타데이터 저장 + 원문 링크 방식 권장.
- **경쟁사 공식 IR·보도자료 — ✅ 가능**: 공개 배포 목적 자료. RSS/공식 페이지 구독 방식, 요약 인용 + 출처 표기.

## 설계 반영 사항

1. **수집기 1차 구현 대상**: 나라장터 API + 지방재정365(data.go.kr 경로) + DART API + 워크넷/고용24 API — 법적 리스크가 낮은 4종부터.
2. **설계 변경**: 데이터 소스 총괄표(설계서 2.1)의 "채용공고(사람인·잡코리아) 크롤링" → **"채용정보 API(워크넷/고용24 기본 + 사람인 공식 API 보조)"로 대체.**
3. **네이버 데이터랩**: 1차 범위에서 제외하거나 "실시간 조회·표시(비축적)" 방식으로 축소. 축적이 필요해지면 NCP 유료 계약 검토.
4. **법무 확인 필요 목록**: ① DART 약관 원문(유료화 금지 조항) ② 열린재정 공공누리 유형 ③ 사람인 API 용도 승인 ④ 데이터랩 사내 이용 범위 질의.
